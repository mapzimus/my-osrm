# Every Walmart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 65 s Optimal Drives video (TikTok + Reels) of the fastest trip to every Walmart store in the 50 states and Puerto Rico.

**Architecture:** A new experiment folder `experiments/walmart/` in the shape of `experiments/amusement_parks/`: `extract.sh` (osmium) → `inventory.py` (stores.json) → `build.py` (drive-time matrix in cached 500×500 blocks, LKH-3 solve in Docker, route geometry) → `video.py` (reel_kit). Pure helpers live in small modules (`matrix.py`, `lkh.py`, `flights.py`) so they can be tested without the engine. `build.py` imports `get`, `polyline`, `km`, `drive`, `label`, `islands` from `amusement_parks/build.py` instead of copying them.

**Tech Stack:** Python 3.14 (`C:\Users\mhowe\AppData\Local\Python\bin\python.exe`, called `$PY` below), numpy, shapely, pyshp, scipy, OR-Tools (test baseline only), pytest; Docker images `iboates/osmium` and a new `walmart-lkh` (LKH-3.0.13 built from source); OSRM na-ferry engine at `http://127.0.0.1:5002` (`--max-table-size 8000`, default `--max-viaroute-size 500`).

**Spec:** `docs/superpowers/specs/2026-10-14-walmart-design.md`

## Global Constraints

- Stores: Walmart Supercenters, Discount Stores, Neighborhood Markets. Not Sam's Club, fuel stations, separately mapped pharmacies/vision/auto centers, closed stores.
- Coverage: 50 states + Puerto Rico. No-road legs are flights: great-circle at 550 mph + 2 h airport time.
- Drive time only: no shopping, sleep, traffic.
- Solver: LKH-3.
- Stop gate: if the store count is short of Walmart's official US count by more than 2 %, stop and report to Max.
- Every build step caches its output and is skipped when the cache exists.
- Video: 65 s, silent, TikTok and Reels, house style from `experiments/reel_kit.py` and `docs/optimal-drives-format.md`.
- Never hold the full matrix as Python lists (21 M floats as Python objects is ~1.5 GB): numpy float32 / int32 only. The PC has hit memory limits twice today.

## Review Focus

1. A mainland store whose point snaps to a one-way stub (row or column mostly NaN) → it is re-snapped to a nearby road that works both ways, not silently dropped or flown to (Task 4 test `test_bad_rows`).
2. A driving run longer than 500 waypoints → the route is fetched in chunks of ≤ 400 that join exactly (Task 4 test `test_chunks_overlap`).
3. Island costs near the LKH integer limit → all costs fit in int32 with headroom (Task 3 test `test_costs_fit`).
4. One store mapped twice (building polygon + point, or store + Vision Center sharing a name) → counted once (Task 1 test `test_dedupe`).
5. A crash mid-matrix → rerun resumes from the finished blocks (Task 2 test `test_resume_skips_done_blocks`).

```python
"""Every Walmart store in the 50 states and Puerto Rico, one point each
(Max, 2026-10-14: all store types, not Sam's Club).

From OSM (extract.sh): features with brand:wikidata=Q483551 or brand=Walmart.
A store is a shop (department store, supermarket, general, variety) that is
not a fuel station, pharmacy, vision or auto centre, pickup locker or closed.
One store mapped twice (building and point) within DEDUPE_M is kept once,
the polygon preferred.

    python experiments/walmart/inventory.py

Writes cache/stores.json; prints the count beside Walmart's official count
and stops (exit 1) if OSM is short by more than GATE.
"""

from __future__ import annotations

import collections
import json
import math
import sys
from pathlib import Path

import numpy as np
from scipy.spatial import cKDTree
from shapely.geometry import shape

HERE = Path(__file__).resolve().parent
CACHE = HERE / "cache"
SHOPS = {"department_store", "supermarket", "general", "variety_store"}
NOT_STORE = ("fuel", "pharmacy", "vision", "auto care", "tire", "pickup", "money center", "sam's")
DEDUPE_M = 150
# Walmart U.S. stores incl. Puerto Rico (Supercenters + Discount + Neighborhood
# Markets). Set from corporate.walmart.com "location facts" on the day of the run.
OFFICIAL = 4_606
GATE = 0.02


def is_store(p: dict) -> bool:
    name = (p.get("name") or "").lower()
    if p.get("shop") not in SHOPS or p.get("amenity") or p.get("opening_hours") == "closed":
        return False
    return not any(w in name for w in NOT_STORE)


def kind(name: str) -> str:
    n = name.lower()
    return "market" if "neighborhood market" in n else "supercenter" if "supercenter" in n else "store"


def dedupe(stores: list[dict], m: float = DEDUPE_M) -> list[dict]:
    """Keep one store per cluster closer than m metres; polygons (area=1) first."""
    stores = sorted(stores, key=lambda s: -s.get("area", 0))
    k = math.cos(math.radians(38))
    xy = np.array([(s["lon"] * k * 111_200, s["lat"] * 111_200) for s in stores])
    tree, gone, out = cKDTree(xy), set(), []
    for i, s in enumerate(stores):
        if i in gone:
            continue
        out.append(s)
        gone.update(tree.query_ball_point(xy[i], m))
    return out


def main() -> None:
    stores = []
    for region in ("us", "puerto-rico"):
        for f in json.load(open(CACHE / f"osm_{region}.geojson", encoding="utf-8"))["features"]:
            p = f["properties"]
            if not is_store(p):
                continue
            g = shape(f["geometry"])
            pt = g.representative_point()
            stores.append(dict(name=p.get("name") or "Walmart", kind=kind(p.get("name") or ""),
                               lon=round(pt.x, 6), lat=round(pt.y, 6), region=region,
                               osm=str(p.get("@id", f.get("id", ""))), area=int(g.geom_type != "Point")))
    n_raw = len(stores)
    stores = dedupe(stores)
    for s in stores:
        s.pop("area")
    json.dump(stores, open(CACHE / "stores.json", "w", encoding="utf-8"), indent=0)
    by = collections.Counter(s["kind"] for s in stores)
    short = 1 - len(stores) / OFFICIAL
    print(f"{len(stores)} stores ({n_raw - len(stores)} duplicates merged): {dict(by)}; "
          f"official {OFFICIAL:,}, OSM {'short' if short > 0 else 'over'} by {abs(short):.1%}")
    if short > GATE:
        sys.exit(f"STOP: OSM is missing more than {GATE:.0%} of stores. Report to Max before building.")


if __name__ == "__main__":
    main()
```

- [ ] **Step 3: Write matrix.py**

```python
"""Drive time and distance between every pair of points, fetched from the
engine in size x size blocks (each request carries at most 2 * size points,
so URLs stay short) and cached block by block: a crash resumes where it
stopped. NaN = the engine found no route."""

from __future__ import annotations

import json
from pathlib import Path

import numpy as np


def blocks(n: int, size: int) -> list[tuple[int, int]]:
    return [(a, min(a + size, n)) for a in range(0, n, size)]


def _block(pts, a, b, get, polyline, osrm):
    (a0, a1), (b0, b1) = a, b
    same = a == b
    sub = pts[a0:a1] if same else pts[a0:a1] + pts[b0:b1]
    la = a1 - a0
    src = ";".join(map(str, range(la)))
    dst = src if same else ";".join(map(str, range(la, la + b1 - b0)))
    d = get(f"{osrm}/table/v1/driving/polyline({polyline(sub)})?sources={src}&destinations={dst}"
            "&annotations=duration,distance")
    f = lambda rows: np.array([[np.nan if v is None else v for v in r] for r in rows], np.float32)  # noqa: E731
    return f(d["durations"]), f(d["distances"]), [w["location"] for w in d["sources"]]


def table(pts: list[list[float]], get, polyline, osrm: str, cache: Path, size: int = 500):
    cache.mkdir(parents=True, exist_ok=True)
    n = len(pts)
    key = cache / "points.json"
    if key.exists() and json.load(open(key)) != pts:          # different points: start over
        for f in cache.glob("*.npz"):
            f.unlink()
    json.dump(pts, open(key, "w"))
    dur = np.full((n, n), np.nan, np.float32)
    dist = np.full((n, n), np.nan, np.float32)
    road: list = [None] * n
    bl = blocks(n, size)
    for a in bl:
        for b in bl:
            f = cache / f"{a[0]}_{b[0]}.npz"
            if not f.exists():
                t, d, r = _block(pts, a, b, get, polyline, osrm)
                np.savez(f, t=t, d=d, r=np.array(r, np.float64))
            z = np.load(f)
            dur[a[0]:a[1], b[0]:b[1]] = z["t"]
            dist[a[0]:a[1], b[0]:b[1]] = z["d"]
            if road[a[0]] is None:
                road[a[0]:a[1]] = z["r"].tolist()
        print(f"  matrix rows {a[1]:,}/{n:,}", flush=True)
    return dur, dist, road
```

- [ ] **Step 4: Write lkh.py**

```python
"""Open-path asymmetric TSP with LKH-3 (Docker image walmart-lkh).

Free start and end: a dummy node 0 costs nothing to or from every stop,
except stops in no_ends (island stops: a round trip by plane can't be where
the trip starts or ends), which cost NO_END to or from the dummy. The tour
LKH returns is rotated to begin after the dummy, which is then dropped."""

from __future__ import annotations

import subprocess
from pathlib import Path

import numpy as np

IMAGE = "walmart-lkh"
LIMIT = 50_000_000      # LKH works in int; ATSP doubles the graph and adds big constants: keep headroom
NO_END = 20_000_000


def to_int(cost: np.ndarray) -> np.ndarray:
    c = np.rint(cost)
    if np.nanmax(c) >= LIMIT:
        raise ValueError(f"cost {np.nanmax(c):.0f} >= LKH limit {LIMIT}")
    return c.astype(np.int32)


def write_problem(cost: np.ndarray, no_ends: list[int], path: Path) -> None:
    n = len(cost)
    full = np.zeros((n + 1, n + 1), np.int32)
    full[1:, 1:] = to_int(cost)
    for k in no_ends:
        full[0, k + 1] = full[k + 1, 0] = NO_END
    with open(path, "w") as f:
        f.write(f"NAME: walmart\nTYPE: ATSP\nDIMENSION: {n + 1}\nEDGE_WEIGHT_TYPE: EXPLICIT\n"
                "EDGE_WEIGHT_FORMAT: FULL_MATRIX\nEDGE_WEIGHT_SECTION\n")
        np.savetxt(f, full, fmt="%d")
        f.write("EOF\n")


def read_order(path: Path) -> list[int]:
    lines = path.read_text().split("TOUR_SECTION")[1].split()
    tour = [int(v) for v in lines if v not in ("-1", "EOF")]
    k = tour.index(1)
    return [v - 2 for v in tour[k + 1:] + tour[:k]]


def solve_open(cost: np.ndarray, no_ends: list[int], workdir: Path, seconds: int) -> list[int]:
    workdir.mkdir(parents=True, exist_ok=True)
    write_problem(cost, no_ends, workdir / "p.atsp")
    (workdir / "p.par").write_text(
        "PROBLEM_FILE = /w/p.atsp\nOUTPUT_TOUR_FILE = /w/p.tour\nRUNS = 1\nSEED = 1\n"
        f"TIME_LIMIT = {seconds}\nPRECISION = 1\nTRACE_LEVEL = 1\n")
    subprocess.run(["docker", "run", "--rm", "-v", f"{workdir.resolve()}:/w", IMAGE, "/w/p.par"], check=True)
    return read_order(workdir / "p.tour")
```

```python
"""Flight legs (amusement-parks rule, Max 2026-10-13): drive to an airport,
fly great-circle at FLIGHT_MPH plus AIRPORT_H, drive on. Mainland <-> island
uses that island's hubs (airports with nonstops); island <-> island flies
directly; Hawaii's islands fly between their own airports."""

from __future__ import annotations

import math

FLIGHT_MPH = 550
AIRPORT_H = 2.0
AIRPORTS = {"BOS": (-71.0096, 42.3656), "JFK": (-73.7781, 40.6413), "EWR": (-74.1745, 40.6895),
            "PHL": (-75.2424, 39.8744), "IAD": (-77.4565, 38.9531), "CLT": (-80.9431, 35.2140),
            "ATL": (-84.4277, 33.6407), "MCO": (-81.3089, 28.4312), "MIA": (-80.2870, 25.7959),
            "FLL": (-80.1527, 26.0742), "DTW": (-83.3534, 42.2162), "ORD": (-87.9073, 41.9742),
            "MSP": (-93.2218, 44.8848), "DFW": (-97.0403, 32.8998), "IAH": (-95.3368, 29.9902),
            "DEN": (-104.6737, 39.8561), "PHX": (-112.0116, 33.4352), "LAS": (-115.1398, 36.0840),
            "LAX": (-118.4085, 33.9416), "SFO": (-122.3790, 37.6213), "SEA": (-122.3088, 47.4502),
            "PDX": (-122.5951, 45.5898),
            "SJU": (-66.0018, 18.4394),
            "HNL": (-157.9251, 21.3245), "OGG": (-156.4305, 20.8986), "KOA": (-156.0456, 19.7388),
            "ITO": (-155.0485, 19.7203), "LIH": (-159.3390, 21.9760)}
ISLAND = {"PR": ["SJU"], "HI": ["HNL", "OGG", "KOA", "ITO", "LIH"]}
HUBS = {"PR": ["BOS", "JFK", "EWR", "PHL", "IAD", "CLT", "ATL", "MCO", "MIA", "FLL", "ORD", "DTW", "DFW", "IAH"],
        "HI": ["LAX", "SFO", "SEA", "PDX", "PHX", "LAS", "DEN", "DFW", "IAH", "ORD", "ATL", "MSP"]}


def km(a, b) -> float:
    la1, la2 = math.radians(a[1]), math.radians(b[1])
    h = math.sin((la2 - la1) / 2) ** 2 + math.cos(la1) * math.cos(la2) * math.sin(math.radians(b[0] - a[0]) / 2) ** 2
    return 2 * 6371 * math.asin(math.sqrt(h))


def flight_s(a, b) -> float:
    return (km(a, b) / 1.609344 / FLIGHT_MPH + AIRPORT_H) * 3600


def options(ri: str, rj: str) -> list[tuple[str, str]]:
    dep = ISLAND[ri] if ri in ISLAND else HUBS[rj]
    arr = ISLAND[rj] if rj in ISLAND else HUBS[ri]
    return [(a, b) for a in dep for b in arr if a != b]


def best_hop(i, j, ri, rj, to, frm, codes) -> tuple[float, tuple[str, str] | None]:
    """to[i, k]: store i to airport codes[k]; frm[k, j]: airport to store j."""
    ix = {c: k for k, c in enumerate(codes)}
    best = (math.inf, None)
    for a, b in options(ri, rj):
        da, db = to[i, ix[a]], frm[ix[b], j]
        if not (math.isnan(da) or math.isnan(db)):
            c = float(da) + flight_s(AIRPORTS[a], AIRPORTS[b]) + float(db)
            if c < best[0]:
                best = (c, (a, b))
    return best
```

- [ ] **Step 4: Write build.py**

```python
"""Fastest trip to every Walmart in the 50 states and Puerto Rico.

Stores: cache/stores.json (inventory.py). Matrix: matrix.py, cached blocks.
No road between two stores (Hawaii, Puerto Rico, Hawaii's islands): fly
(flights.py). Island crossings carry a solver-only penalty so each island
group is one visit, not a shortcut. Order: LKH-3 (lkh.py), free start and end.
Drive time only: no shopping, sleep or traffic.

    python experiments/walmart/build.py               # cached steps are skipped
    python experiments/walmart/build.py --sample 50   # trial: 50 stores near Atlanta, in cache/sample50/
    python experiments/walmart/build.py --resolve     # re-run the solver

Writes cache/tour.json (or cache/sampleN/tour.json) for video.py.
"""

from __future__ import annotations

import argparse
import importlib.util
import json
import math
from pathlib import Path

import numpy as np

import flights as F
import lkh
import matrix

HERE = Path(__file__).resolve().parent
_spec = importlib.util.spec_from_file_location("parks_build", HERE.parent / "amusement_parks" / "build.py")
P = importlib.util.module_from_spec(_spec)
_spec.loader.exec_module(P)

SOLVE_SECONDS = 1200
ISLAND_PENALTY = 1_000_000            # seconds, solver only
ROUTE_CHUNK = 400                     # engine's max-viaroute-size is 500
MAX_DRIVE_LEG_H = 12


def bad_rows(dur: np.ndarray, frac: float = 0.5) -> list[int]:
    """Stores the engine can't leave or can't reach from most others."""
    n = len(dur)
    miss = np.isnan(dur).sum(1) + np.isnan(dur).sum(0)
    return [int(i) for i in np.flatnonzero(miss > frac * n)]


def chunks(n: int, size: int = ROUTE_CHUNK) -> list[tuple[int, int]]:
    """Inclusive index ranges of at most size stops; each starts where the last ended."""
    out, a = [], 0
    while True:
        b = min(a + size - 1, n - 1)
        out.append((a, b))
        if b == n - 1:
            return out
        a = b


def check_tour(tour: dict, n: int) -> None:
    names = [s["name"] + str(s.get("lon", "")) + str(s.get("lat", "")) for s in tour["stops"]]
    assert len(names) == n and len(set(names)) == n, "every store exactly once"
    ts = [s["t"] for s in tour["stops"]]
    assert all(b >= a for a, b in zip(ts, ts[1:])), "arrival times increase"
    assert abs(tour["t"][-1] / 3600 - tour["hours"]) < 1e-6, "clock ends at the total"
    # Alaska is reached by road through Canada (~40 h from Washington): exempt.
    assert all(leg["h"] <= MAX_DRIVE_LEG_H or leg.get("alaska") for leg in tour["legs"]), "no driving leg over 12 h"


def region(s: dict) -> str:
    if s["region"] == "puerto-rico":
        return "PR"
    return "HI" if -161 < s["lon"] < -154 and 18 < s["lat"] < 23 else "US"


def resnap(stores, dur, dist, road, bad):
    """Move each bad store to the nearest road that works both ways with a
    well-connected store; patch its row and column."""
    ok = int(np.argmin(np.isnan(dur).sum(1)))
    for i in bad:
        s = stores[i]
        for w in P.get(f"{P.OSRM}/nearest/v1/driving/{s['lon']},{s['lat']}?number=12")["waypoints"][1:]:
            d = P.get(f"{P.OSRM}/table/v1/driving/polyline({P.polyline([w['location'], road[ok]])})"
                      "?annotations=duration")["durations"]
            if d[0][1] is not None and d[1][0] is not None:
                road[i] = w["location"]
                pts = [road[i]] + road
                for kind, q in (("row", f"sources=0&destinations={';'.join(map(str, range(1, len(pts))))}"),
                                ("col", f"sources={';'.join(map(str, range(1, len(pts))))}&destinations=0")):
                    r = P.get(f"{P.OSRM}/table/v1/driving/polyline({P.polyline(pts)})?{q}"
                              "&annotations=duration,distance")
                    t = np.array(r["durations"], dtype=np.float64).ravel().astype(np.float32)
                    dd = np.array(r["distances"], dtype=np.float64).ravel().astype(np.float32)
                    if kind == "row":
                        dur[i, :], dist[i, :] = t, dd
                    else:
                        dur[:, i], dist[:, i] = t, dd
                print(f"  resnapped {s['name']} ({s['lon']:.4f}, {s['lat']:.4f}): {w['distance']:.0f} m")
                break


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--sample", type=int)
    ap.add_argument("--resolve", action="store_true")
    args = ap.parse_args()

    cache = HERE / "cache"
    stores = json.load(open(cache / "stores.json", encoding="utf-8"))
    if args.sample:
        atl = (-84.39, 33.75)
        stores = sorted(stores, key=lambda s: F.km((s["lon"], s["lat"]), atl))[:args.sample]
        cache = cache / f"sample{args.sample}"
        cache.mkdir(exist_ok=True)
    stores.sort(key=lambda s: (s["lon"], s["lat"]))
    for s in stores:
        s["region"] = region(s)
    n = len(stores)

    dur, dist, road = matrix.table([[s["lon"], s["lat"]] for s in stores], P.get, P.polyline, P.OSRM,
                                   cache / "matrix")
    bad = [i for i in bad_rows(dur) if stores[i]["region"] == "US"]
    if bad:
        resnap(stores, dur, dist, road, bad)
    still = [i for i in bad_rows(dur) if stores[i]["region"] == "US"]
    if still:
        print("dropped (no road connection):", [(stores[i]["name"], stores[i]["lon"], stores[i]["lat"]) for i in still])
        keep = [i for i in range(n) if i not in still]
        stores = [stores[i] for i in keep]
        dur, dist = dur[np.ix_(keep, keep)], dist[np.ix_(keep, keep)]
        road = [road[i] for i in keep]
        n = len(stores)
    for s, r in zip(stores, road):
        s["road"] = r

    # Different Hawaiian islands: no car ferry, so no road.
    isl = P.islands(stores)
    hi = [i for i in range(n) if isl[i] is not None]
    for a in hi:
        for b in hi:
            if isl[a] != isl[b]:
                dur[a, b] = dist[a, b] = np.nan

    codes = list(F.AIRPORTS)
    apts = [list(F.AIRPORTS[c]) for c in codes]
    reg = [s["region"] for s in stores]
    need = sorted({i for i in range(n) if reg[i] != "US"})
    to = frm = None                   # only used for no-road pairs, which need island stores
    if need:
        # Drive times store <-> airport for the stores that fly, and airport <-> every store.
        am_to, _, _ = matrix.table([s["road"] for s in stores] + apts, P.get, P.polyline, P.OSRM, cache / "air")
        to, frm = am_to[:n, n:], am_to[n:, :n]
    cost = dur.astype(np.float64)
    pen = 0
    for i, j in zip(*np.nonzero(np.isnan(dur))):
        c, _ = F.best_hop(i, j, reg[i], reg[j], to, frm, codes)
        both_islands = reg[i] != "US" and reg[j] != "US" and reg[i] != reg[j]
        cost[i, j] = c + (ISLAND_PENALTY if reg[i] != reg[j] else 0) + (10 * ISLAND_PENALTY if both_islands else 0)
        pen += 1
    print(f"{n} stores, {pen:,} no-road pairs priced as flights")

    op = cache / "order.json"
    if args.resolve or not op.exists() or len(json.load(open(op))) != n:
        order = lkh.solve_open(cost, [i for i in range(n) if reg[i] != "US"], cache / "lkh", SOLVE_SECONDS)
        json.dump(order, open(op, "w"))
    order = json.load(open(op))
    stops = [stores[i] for i in order]

    # Timeline: driving runs split at flights; each run routed in chunks.
    coords, t, dists, mode, flights, ferries, legs_info = [], [], [], [], [], [], []
    clock = metres = 0.0

    def push(c, dt, dd, md):
        nonlocal clock, metres
        clock += dt
        metres += dd
        coords.append(c)
        t.append(clock)
        dists.append(metres)
        mode.append(md)

    def drive_run(rs):
        for a, b in chunks(len(rs)):
            part = rs[a:b + 1]
            if len(part) < 2:
                continue
            for li, leg in enumerate(P.drive(part)):
                kt = leg["t"] / max(sum(leg["seg_t"]), 1e-9)
                kd = leg["d"] / max(sum(leg["seg_d"]), 1e-9)
                for c, dt, dd, fe in zip(leg["coords"][1:], leg["seg_t"], leg["seg_d"], leg["ferry"][1:]):
                    push(c, dt * kt, dd * kd, "ferry" if fe else "road")
                    if fe:
                        if ferries and ferries[-1]["i1"] == len(coords) - 2:
                            ferries[-1]["i1"] = len(coords) - 1
                        else:
                            ferries.append(dict(i0=len(coords) - 2, i1=len(coords) - 1, names={}))
                        ferries[-1]["names"][fe] = ferries[-1]["names"].get(fe, 0) + dd
                legs_info.append(dict(frm=part[li]["name"], to=part[li + 1]["name"], h=leg["t"] / 3600,
                                      mi=leg["d"] / 1609.344, ferry=any(leg["ferry"]),
                                      alaska=min(part[li]["road"][0], part[li + 1]["road"][0]) < -129))
                part[li + 1]["t"] = clock

    run = [stops[0]]
    push(stops[0]["road"], 0, 0, "road")
    stops[0]["t"] = 0.0
    for k in range(1, n):
        i, j = order[k - 1], order[k]
        if not np.isnan(dur[i, j]):
            run.append(stops[k])
            continue
        drive_run(run)
        _, (ca, cb) = F.best_hop(i, j, reg[i], reg[j], to, frm, codes)
        pa = [float(v) for v in apts[codes.index(ca)]]
        pb = [float(v) for v in apts[codes.index(cb)]]
        drive_run([stops[k - 1], dict(name=ca, road=pa)])
        t0 = clock
        push(pb, F.flight_s(F.AIRPORTS[ca], F.AIRPORTS[cb]), 0, "flight")
        flights.append(dict(frm=ca, to=cb, a=pa, b=pb, t0=t0, t1=clock, a_town=ca, b_town=cb))
        run = [dict(name=cb, road=pb), stops[k]]
    drive_run(run)

    for f in ferries:
        named = {k: v for k, v in f.pop("names").items()
                 if k != "Ferry" and not any(w in k for w in ("Approach", "Berth", "Ramp", "Terminal"))}
        f["name"] = max(named, key=named.get) if named else "Ferry"
    P.label(stops)
    hours = clock / 3600
    fly_h = sum(f["t1"] - f["t0"] for f in flights) / 3600
    tour = dict(stops=stops, coords=coords, t=t, dist=dists, mode=mode, flights=flights, ferries=ferries,
                legs=legs_info, hours=hours, fly_hours=fly_h, miles=metres / 1609.344,
                flown_miles=sum(F.km(f["a"], f["b"]) for f in flights) / 1.609344)
    check_tour(tour, n)
    json.dump(tour, open(cache / "tour.json", "w"))
    print(f"{n} stores, {hours:.1f} h ({hours - fly_h:.1f} h driving, {len(flights)} flights {fly_h:.1f} h), "
          f"{metres / 1609.344:,.0f} mi, {len(ferries)} ferries, {stops[0]['name']} -> {stops[-1]['name']}")


if __name__ == "__main__":
    main()
```

`P.drive(stops)` reads `s["road"]` from each stop and `P.label(stops)` sets `state` and `town`; both come from `amusement_parks/build.py` unchanged.

```python
def end_rows(tour: dict) -> tuple[list[tuple[str, str]], list[str]]:
    st = tour["stops"]
    drive_h = tour["hours"] - tour["fly_hours"]
    by_state = collections.Counter(s["state"] for s in st)
    top, top_n = by_state.most_common(1)[0]
    rows = [(f"{drive_h:,.0f} hours", "of driving, nonstop"),
            (f"{tour['miles']:,.0f} miles", f"{len(tour['flights'])} flights to Hawaii and Puerto Rico"),
            (f"{len(st):,} Walmarts", f"most in one state: {top}, {top_n}"),
            (f"{drive_h / DRIVE_DAY_H:,.0f} days", f"at {DRIVE_DAY_H} h of driving a day")]
    footer = [f"Start: {st[0]['town']}, {st[0]['state']}   Finish: {st[-1]['town']}, {st[-1]['state']}",
              "Stores: OpenStreetMap (Oct 2026)   Routing: OSRM"]
    return rows, footer
```
